
## Portfolio Interactivo 3D

Este proyecto es un portfolio personal en formato videojuego interactivo. Un personaje 3D puede moverse por una habitación e interactuar con objetos (ordenador, portátil, libro, estantería, cama), cada uno mostrando información personal o de proyectos.

### Tecnologías
- React
- Vite
- Three.js
- @react-three/fiber
- @react-three/drei

### Instalación y uso
```bash
npm install
npm run dev
```

### Personalización
Sustituye los modelos y textos por tu información personal y proyectos.
